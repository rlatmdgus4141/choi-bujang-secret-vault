# 8단계 · 자원 구역과 확인 범위

2026-10-13의 수정 공지를 반영합니다. 이전 버전의 등록 자원 권한표와 연습용 사용자 고정은 이번 계약의 요구가 아닙니다.
판정기는 경로·동작을 검사하고, 실제 행 소유자는 자료 API가 확인합니다. 요청에 강사 역할이 없으므로 판정기는 공지 쓰기를 모두 거부합니다.

## 판정기 정책

기존 `device_registered`, `step_up_required` 검사와 응답 다섯 항목, 기존 이유 코드를 유지합니다.
엔진이 확인한 반·프로젝트·가명 주체·기기 항목이 있어야 하며, 특정 연습 사용자나 기기 ID에 실제 정상 접근을 고정하지 않습니다.
브라우저 본문·헤더의 role, owner_id, grants는 권한 근거로 사용하지 않습니다.

| 서비스와 정확한 경로 | 메서드 | 판정기 경로 정책 |
|---|---|---|
| notes: /notes/:id 또는 /api/notes/:id | GET · PUT · DELETE | 정상 기기/접속이면 허용; 행 소유자는 API에서 검사 |
| notes: /notes 또는 /api/notes | POST | 서버가 검증한 소유자로 추가하는 API에 전달 |
| notes: /notes 또는 /api/notes | GET | 전체 목록 경로 거부 |
| notices: /notices, /notices/:id 또는 /api/notices, /api/notices/:id | GET | 로그인한 주체의 공유 공지 읽기 경로 허용 |
| 공지·강사 자료 | POST · PUT · PATCH · DELETE | 역할 계약이 없으므로 모두 거부 |
| 알 수 없는 서비스/경로, export·list·all·중첩·인코딩 우회, path/route 불일치 | 모든 메서드 | 거부 |

개별 자원 ID는 안전한 단일 경로 조각으로만 받습니다. 예약된 기능 이름은 자원 ID가 아닙니다.
실제 메모 API는 UUID를 다시 검사합니다. 판정기가 `:id` 경로를 허용하는 것은 그 행의 소유자를 승인한 결과가 아닙니다.
쿼리 원문을 받지 않는 계약이므로 queryLength가 0이 아닌 요청은 판정기에서 거부합니다.
복합 이상 신호의 요청은 허용 경로라도 추가 확인으로 보내며, 새 로그인은 금지된 구역을 열지 않습니다.

## 최종 API와 자료실

자원 ID `notes.personal`과 `notices.instructor`, 기존 배포 주소·화면·DB는 유지합니다.
메모 목록 API는 로그인 사용자의 owner_id로만 조회합니다. 여러 사람의 목록을 반환하지 않으며,
조회 결과에 다른 소유자가 한 건이라도 섞이면 전체 응답을 거부합니다. 브라우저의 기존 본인 목록은 이 API를 사용합니다.
한 건 조회는 저장된 owner_id와 id를 응답 전 다시 검사하고, 타인/소유자 누락/없는 메모는 본문 없이 404입니다.
수정·삭제는 id와 검증한 사용자 owner_id를 같은 DB 요청에 적용합니다. 추가/수정의 owner_id는 서버가 정합니다.
공지 API는 Auth Admin 조회의 현재 app_metadata.vault_role을 매번 검사합니다. 요청 본문·화면 메뉴의 role은 신뢰하지 않습니다.
판정기의 역할 없는 공지 쓰기 거부와 API의 별도 강사 권한 검사는 모두 유지합니다.

## 재현

```sh
npm run decider:test
npm run fixture:7
node --test test/stage8-decider.test.mjs test/stage8-owner-read.test.mjs test/stage3.test.mjs
npm test
npm run bundle
```

판정기 모의 시험은 새 A/B 가명 주체·다른 메모 ID의 정상 경로를 허용하고, 모든 메모 전체 목록·공지 쓰기·예약 경로를 거부합니다.
원본 로그인 검증 도우미를 사용한 서명 토큰 모의 API 시험은 A/B 자기 자료 CRUD를 유지하고 상대 자료 읽기·수정·삭제를 거부합니다.
판정기가 허용한 한 건 경로에서도 최종 API의 저장 소유자 검사가 본문을 보호하는 연결을 시험합니다.
기기 등록/복합 이상 접속, 경로/쿼리 우회와 이전 XDR 6개 회귀 시험을 함께 실행합니다.

실제 A/B 계정의 비밀번호·JWT를 읽거나 기록하지 않습니다. 실제 로그인 계정으로 한 배포 CRUD 실측은 이번 작업에서 미실행입니다.
배포 뒤 `npm run bundle`은 현재 커밋 식별 정보, 정적 메모 제거, 무로그인 API 거부, 원본 자료 권한과 로컬 구역 규칙을 자기 점검합니다.
로컬 가상 사건과 모의 API 시험은 심판 판정으로 표시하지 않습니다. 공지 수정 전후의 구현 이력은 Git 기록에 보존됩니다.
