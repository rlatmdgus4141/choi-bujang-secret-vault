# XDR 5 · 권한 가로채기 탐지

## 근거와 판단

- T1068: https://attack.mitre.org/techniques/T1068/
- T1078: https://attack.mitre.org/techniques/T1078/
- 그룹 조작의 실제 기법 T1098.007: https://attack.mitre.org/techniques/T1098/007/

T1068은 취약점 악용으로 권한을 높이는 기법입니다. 관리자 명령 발생만으로 취약점 악용 성공을 단정하지 않습니다.
관리자 그룹 추가와 비정상 접속·즉시 명령 실행·여러 계정의 추가, 세션 승격과 낯선 접속/권한 사용,
평소 시간 밖 낯선 접속의 관리자 명령, 제거 직후 재승격 같은 상관 요약을 신뢰된 Wazuh 경보에서 찾습니다.
규칙 수준 10 이상·관련 기법·유효한 주소·계정과 구체적인 복합 신호가 있을 때만 block입니다.
일반 그룹 추가, 권한 창 취소, 명령 실패, 그룹 조회, 평소 관리자 작업에는 자동 거부하지 않습니다.
승인된 변경·그룹 형식 오류·상관 숫자 불일치·권한을 낮추는 사건은 높은 수준만으로 차단하지 않습니다.
규칙 수준 10·그룹 여러 계정 3건·재승격 5분·확신도 기준 0.85/0.5는 학습 정책이며 MITRE 고정 수치가 아닙니다.
특정 경보 번호·계정 이름·주소를 정답 표로 사용하지 않습니다.

## 읽기와 독립 실행

read-alerts.mjs는 시각·주소·계정·규칙 수준·설명만 추출하며 비밀값을 지운 뒤 한 경보당 한 줄을 출력합니다.
patterns.json과 decide.mjs의 상단 상수는 동일합니다. decide는 {action,confidence,reason}만 반환합니다.
다른 파일/패키지·Node 전역·네트워크 없이 격리 VM에서 한 파일만 실행해 26건을 분류했습니다.
원본 fixture blob은 442fc3297bcc73969fa61b1368d08e0038b9c135이며 변경하지 않았습니다.

## 계정과 세션 대응

respond는 판단을 다시 계산합니다. 신뢰된 경보의 후보이고 발생 후 5분 안일 때만 15분 만료의 거부 규칙을 추가합니다.
가상 경보에는 실제 로그인 세션 ID가 없습니다. 연습 매핑은 agent·계정·출발 주소를 함께 묶어 그 맥락을 거부합니다.
동일 IP의 다른 계정이나 다른 정상 맥락은 차단하지 않습니다. 전 계정의 모든 로그인 세션을 회수한 것으로 표현하지 않습니다.
운영 제공자가 확인한 세션은 trustedTargetForAlert/Request 콜백에서 {scope:'session',namespace,sessionId}로 연결할 수 있습니다.
이 경우 다른 네트워크로 옮겨도 같은 세션을 거부하고 다른 세션·프로젝트는 보존합니다.
원문 계정/주소/세션 ID는 규칙 파일이나 감사 로그에 쓰지 않고 대상의 SHA-256 지문을 기록합니다.
규칙에는 만료 시각과 근거 경보 번호를 붙이며 중복 전달은 만료를 갱신하지 않습니다.

createVaultXdrGate는 기존 src/decider.mjs를 그대로 호출하는 추가 게이트입니다.
브라우저가 보낸 account/sourceIp/sessionId를 읽어 회수 대상을 고르지 않습니다.
현재 엔진의 18개 계약 필드만으로 Wazuh 계정을 실제 로그인 세션에 매핑할 수 없어 운영 연결은 미검증입니다.
Auth 서버 세션 삭제·JWT 생성·토큰 원문 기록은 수행하지 않습니다. DB와 기존 판정기 규칙도 변경하지 않습니다.
현재 저장소는 한 프로세스의 직렬 쓰기와 원자적 파일 교체를 사용하며 분산 운영 저장소를 완료했다고 주장하지 않습니다.

## 결과와 재현

26건에서 block 9 · alert 8 · record 9입니다. 정상 9건의 block 0입니다.
가상 재생의 추가 게이트가 후보 9건을 거부하고 정상 9건을 모의 기본 허용 정책에 전달했습니다.
이는 실제 운영 엔진이나 모든 실제 세션의 정상 접근을 검증했다는 뜻이 아닙니다.
새 계정/주소/그룹, 승격 취소/실패·일반 그룹·평소 관리자 요청·숫자 불일치, 만료/중복,
같은 IP의 다른 계정, 다른 정상 접속, 제공자 세션 ID를 쓰는 주소 이동을 시험했습니다.

1. npm run xdr:privilege:read — 경보 26건, 출력 26줄.
2. npm run xdr:run -- privilege — result.json 갱신.
3. npm run xdr:privilege:respond — 가상 시각 재생, normalBlocked 0.
4. node --test test/xdr-privilege.test.mjs — 과제별 9개 시험.
5. npm test — 기존 과제 회귀 시험.

연습 규칙은 xdr/runtime/privilege-deny-rules.json, 로그는 xdr/alerts.log이며 Git에서 제외합니다.
오래된 경보를 현재 시각으로 조작하지 않습니다. 실제 시각에 원본 경보를 처리하면 오래된 사건으로 보고 규칙을 만들지 않습니다.
심판은 공개 저장소의 xdr/privilege/decide.mjs를 단독 실행해 별도로 평가합니다.
