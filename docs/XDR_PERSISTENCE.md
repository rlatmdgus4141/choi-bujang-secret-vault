# XDR 4 · 지속성 프로그램 탐지

## 근거와 판단 범위

- 서비스 생성·변경: MITRE T1543, https://attack.mitre.org/techniques/T1543/
- 예약 작업: MITRE T1053, https://attack.mitre.org/techniques/T1053/
- 시작 폴더 자동 실행: MITRE T1547.001, https://attack.mitre.org/techniques/T1547/001/

과제 경보는 시작 폴더 사건 일부도 T1543으로 묶지만 실제 기법 근거는 T1547.001로 구분합니다.
규칙 수준 10 이상, 유효한 출발 주소, 관련 기법 태그에 추가 행위 근거가 겹칠 때만 격리 후보입니다.
서비스는 새 등록 또는 실행 파일 변경과 미서명/기준 목록 밖 신호, 그리고 위험 실행 경로를 비교합니다.
경로가 없는 경우에도 미서명 등록이 명확하게 반복된 상관 요약이면 후보로 삼되 경보 본문/숫자가 충돌하면 자동 차단하지 않습니다.
예약 작업은 낯선 이름·비정상 시간·다른 시작 항목과의 연결이 위험 실행 경로와 함께 있을 때 확인합니다.
시작 폴더는 기준 목록 밖 프로그램이 실제 경로에 추가되는 사건을 확인합니다.
단순히 파일이 임시 폴더에 존재하거나 서명 확인이 되지 않았다는 이유만으로 block하지 않습니다.
기존 서비스도 실행 파일 변조 근거가 있으면 검토합니다. 기존 이름이나 서명 자체가 안전을 보장하지 않습니다.

수치 0.85/0.5·반복 등록 3건·규칙 수준 10·15분 만료는 수업 정책이며 MITRE가 정한 수치가 아닙니다.
평소 목록은 이 모듈이 파일/OS에서 조회하지 않습니다. 신뢰된 Wazuh 경보의 기준 목록 비교 설명만 사용합니다.
어떤 경보 번호·특정 계정·파일명·주소를 정답 표로 사용하지 않습니다.

## 파일과 연결

read-alerts.mjs는 시각·출발 주소·계정·규칙 수준·설명만 반환하며 비밀값을 지우고 한 경보당 한 줄을 출력합니다.
patterns.json과 decide.mjs 상단 상수는 동일한 근거 패턴입니다. decide는 판단 결과 세 항목만 반환합니다.
respond.mjs는 판단을 다시 계산하고 최근 5분 경보의 확실한 후보만 만료 시각과 근거 ID를 붙여 거부 규칙으로 기록합니다.
xdr/alerts.log에는 제한된 감사 항목만 한 줄씩 기록하며 경보 원문·계정·실행 파일·키를 기록하지 않습니다.

createVaultXdrGate는 기존 판정기를 그대로 호출하는 추가 게이트입니다.
출발 주소는 서버 측 신뢰된 콜백으로 받아야 하며 브라우저 sourceIp·헤더를 사용하지 않습니다.
실제 반 엔진 요청에는 Wazuh 출발 주소/PC 전체 매핑이 없어 운영 연결은 미검증입니다.
현재 규칙은 출발 주소 기준 접속 거부이며 운영 에이전트의 기기 전체 격리를 실행했다고 주장하지 않습니다.
로컬 저장소는 한 프로세스의 직렬 쓰기와 원자적 교체를 사용합니다. 분산 운영 저장소 완료를 주장하지 않습니다.

## 결과와 재현

원본 fixture blob: 8dfb349b02cb0fd107a751c148be6165aa8c2725. 원본 24건과 읽기 모듈 출력 24줄이 일치합니다.
block 8 · alert 8 · record 8이며 정상 8건의 block 0입니다.
가상 재생에서 차단 후보 8건을 추가 게이트가 거부하고 정상 8건은 모의 기본 허용 정책에 전달합니다.
원본 판정기의 모든 정상 접근이나 실제 PC 격리를 검증했다는 뜻은 아닙니다.
다른 파일·Node 전역·네트워크가 없는 VM에서 decide.mjs 한 파일만 실행해 같은 결과를 얻었습니다.
새 경보 번호·계정·주소·실행 파일, 동일 의미의 한국어/영어 서비스 변경, 기존 서비스 변조도 시험했습니다.
서명 미확인·정상 업데이트·시작 목록 읽기·설명 변경·상관 숫자 불일치에는 자동 격리하지 않습니다.

1. npm run xdr:persistence:read — 경보 24건, 출력 24줄.
2. npm run xdr:run -- persistence — result.json 갱신.
3. npm run xdr:persistence:respond — 가상 시각 재생, normalBlocked 0.
4. node --test test/xdr-persistence.test.mjs — 과제별 8개 시험.
5. npm test — 기존 과제 회귀 시험.

가상 재생 규칙은 xdr/runtime/persistence-deny-rules.json, 감사 로그는 xdr/alerts.log이며 Git에서 제외합니다.
경보 시각을 실제 현재 시각으로 조작하지 않습니다. 원본 가상 사건은 오래되었으므로 실시간 respond 호출은 차단 규칙을 만들지 않습니다.
심판은 xdr/persistence/decide.mjs를 단독 실행해 별도로 평가합니다.
