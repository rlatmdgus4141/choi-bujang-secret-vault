# 케셰브 · 학생 PC 대시보드 시연·확인 기록

## 1. 버전과 범위

22단계 기준 커밋은 `f96a5f6944b508df6a9d9df2a09ea8b2e65f618f`입니다. 이후 사용자 승인으로 학생 대시보드와 일반 권한 수집 도구 0.1.0을 추가했습니다. 제공 앱 패키지 0.2.14와 기존 제출물은 유지합니다. **현재 버전은 학생 PC 실측 시연 확인·외부 연동 검증 중**이며 새 커밋 번호는 실제 Git 출력으로 기록합니다. v1.0 또는 공식 통과를 선언하지 않습니다.

선택한 화면은 관제 대시보드형, 실행 형태는 포장 없이 프로젝트 폴더에서 실행입니다. 포장 명령·포장 스크립트·새 서버·관리자 권한을 추가하지 않습니다. 실행 명령은 [STUDENT_RUNBOOK.md의 11절](STUDENT_RUNBOOK.md#11-22단계-이후--pc-대시보드-실행)을 따릅니다.

## 5. 제한과 데이터 보존

- 스냅샷 파일을 사용합니다. 브라우저의 다시 조회는 Windows 명령 실행이나 실시간 자동 측정이 아닙니다.
- 관리자 권한이 필요한 항목은 수집하지 않습니다. 접근 거부를 0·정상·안전으로 바꾸지 않습니다.
- Windows 경고·오류 집계는 최근 24시간, 로그별 최대 5,000건입니다. 상한 초과는 일부 집계·최소 건수로 표시합니다.
- 방화벽은 프로필 설정 요약이며 규칙 전체 감사·보안 진단·치료가 아닙니다.
- PC 이름 해시는 같은 이름의 표본을 구분하는 보조값이며 신원·기기 인증 수단이 아닙니다.
- 비교 기록은 현재 페이지 메모리의 최대 20개입니다. F5나 브라우저 재실행 후 초기화되며 수집 JSON 자체는 별도 폴더에 남습니다.
- 실측과 예시를 섞지 않습니다. 불러온 파일의 출처·수집 시각을 표시하며 실패 때 예시를 대신 넣지 않습니다.
- 기존 Git 기록·앞 단계 코드·22단계 문서·자료실 DB·개인 자격은 보존합니다. 수집 JSON의 네트워크 주소나 PC 식별 해시를 커밋하지 않습니다.
- 다른 PC와 macOS·Linux의 실제 PC 수집은 지원 확인이 없습니다. 수집 도구는 Windows만 대상으로 합니다.
